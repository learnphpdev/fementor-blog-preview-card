# Frontend Mentor - 部落格預覽卡

![部落格預覽卡程式挑戰的設計預覽](./preview.jpg)

## 歡迎！👋

感謝您查看這個前端程式挑戰。

[Frontend Mentor](https://www.frontendmentor.io) 的挑戰能協助您透過建置實際專案來提升程式技能。

**要完成這項挑戰，您需要對 HTML 和 CSS 有基本認識。**

## 挑戰說明

您的挑戰是建置這個部落格預覽卡片，並盡可能讓它看起來接近設計稿。

你可以使用任何喜歡的工具來協助完成挑戰。所以如果你想練習某項技能，儘管放手一試。

你的使用者應該能夠：

- 查看頁面上所有互動元素的懸停和對焦狀態

需要一些挑戰的支援嗎？[加入我們的社群](https://www.frontendmentor.io/community)並在 **#協助** 頻道提問。

## 在哪裡可以找到所有內容

您的任務是將這個專案根據 `/design` 資料夾中的設計稿建置出來。您會找到設計的行動裝置版本和電腦版本。

設計稿採用靜態 JPG 格式。使用 JPG 意味著您需要自行判斷 `font-size`、`padding` 和 `margin` 等樣式。

如果您想要檢視更詳細的設計檔案（我們提供 Sketch 和 Figma 版本），可以[訂閱 PRO 會員](https://www.frontendmentor.io/pro)。

本專案所需的所有資源都存放在 `/assets` 資料夾中。圖片已針對正確的螢幕尺寸進行匯出並最佳化。

我們也提供了本專案所需字型的變數與靜態字型檔案。您可以選擇連結至 Google 字型服務，或使用本機字型檔案自行託管字型。請注意，我們已移除本專案不需使用的字重對應之靜態字型檔案。

同時附有一份 `style-guide.md` 檔案，其中包含您所需的資訊，例如配色方案與字型設定。

## 建置您的專案

歡迎使用任何您習慣的工作流程。以下是一個建議的流程，但無需嚴格遵循這些步驟：

1. 在 [GitHub](https://github.com/) 上將您的專案初始化為公開的程式碼儲存庫。建立儲存庫可讓您在需要協助時更容易與社群分享程式碼。若不確定如何操作，[請參考 Try Git 教學資源](https://try.github.io/)。
2. 設定您的程式碼儲存庫以將程式碼發布至網頁地址。當您在挑戰過程中需要協助時，這將非常有用，因為您可以分享專案的 URL 與程式碼儲存庫連結。有多種方式可實現此功能，我們在下方提供了一些建議。
3. 仔細研究設計稿，開始規劃如何處理這個專案。此步驟對於預先規劃 CSS 類別以建立可重複使用的樣式至關重要。
4. 在添加任何樣式之前，先用 HTML 結構化你的內容。先寫好 HTML 可以幫助你集中注意力，打造結構良好的內容。
5. 寫出你的專案基礎樣式，包括一般內容樣式，像是`font-family`和`font-size`。
6. 從頁面頂部開始添加樣式，逐步往下進行。只有當你滿意目前正在處理的區域時，才繼續進行下一個部分。

## 建立自訂的 `README.md`

我們強烈建議用自訂內容覆蓋這個 `README.md`。我們已在此啟動碼的 [`README-template.md`](./README-template.md) 檔案中提供了範本。

該範本提供了新增內容的指引。自訂的 `README` 能幫助您說明專案並反思學習心得。歡迎根據需求自由編輯我們的範本。

當你將資料填入範本後，請刪除此檔案並將`README-template.md`檔案重新命名為`README.md`。這會讓它顯示為你的程式碼儲存庫的 README 檔案。
